# 03_content_plan.md ― 企画担当による投稿ネタ・切り口・コンテンツカレンダー

作成日: 2026-08-28 / 作成者: affiliate-content-planner(企画担当)

前提: `affiliate/00_strategy.md`(ジャンル: 仕事術・自己投資系、重点テーマ: AI活用・AIツール)、`affiliate/01_products.md`(優先着手カテゴリ: 5.書籍要約・オーディオブック / 1.ビジネス系オンライン学習 / 4.生産性・業務効率化SaaS / 3.オンライン英会話)、`affiliate/02_research.md`(フックパターン・ターゲットの生の声・トレンド)をもとに投稿ネタを設計しました。

**運用ルールの再確認**
- 断定・煽り表現(「絶対」「必ず」「誰でも簡単に」等)は使用しない。実体験ベース・「自分の場合はこうだった」の語り口に統一する。
- 広告表記(#PR等)は原稿化の段階でライティング担当・コンプライアンス担当が必ず付与する前提とし、ここでは骨子のみ扱う。
- 比較・ランキング型など「複数リンクへの遷移」が絡む企画には※印を付け、導線設計担当(affiliate-funnel-designer)に事前共有する。
