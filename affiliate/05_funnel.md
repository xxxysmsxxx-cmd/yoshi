# 05_funnel.md ― 導線設計担当による収益導線設計

作成日: 2026-08-28 / 作成者: affiliate-funnel-designer(導線設計担当)

前提: `affiliate/00_strategy.md`(ジャンル: 仕事術・自己投資系、ペルソナ: 25〜38歳会社員、トーン: 実体験型・共感ベース、煽り文句は使わない)、`affiliate/01_products.md`(優先着手カテゴリ: 5→1→4→3、直リンク禁止傾向のカテゴリ2・6は今回保留だが将来追加の可能性あり)、`affiliate/02_research.md`(「プロフィール→リンクまとめ→個別ページ」の2段階導線が業界標準)を踏まえて設計します。

**最初に強調したいこと**: どんなに良い投稿を書いても、この「導線」が弱いと、フォロワーは増えても収益にはつながりません。投稿は入口に過ぎず、実際にお金が動くのはプロフィール〜リンク集〜商品ページの区間です。ここの設計・言葉遣いが雑だと、興味を持った人ほど途中で離脱します。企画・ライティングと同じくらい、あるいはそれ以上に重要な工程として扱ってください。

---

## 導線全体図

### 全体の流れ(テキスト図)

```
【投稿】(X本文 / Instagramキャプション)
   │  ①フックで止める → 共感 → 実体験 → CTA「続きはプロフィールへ」
   ▼
【プロフィール画面】
   │  ②誰の何を解決するアカウントか一瞬で伝わるか
   │    実績・信頼性の一言があるか
   │    リンクへの誘導文言が投稿のCTAと一致しているか
   ▼
【リンク集(lit.link等)】
   │  ③今の自分に関係ある項目がすぐ見つかるか
   │    ラベルが投稿・プロフィールの言葉と一致しているか
   │    案件が多すぎて迷わせていないか
   ▼
【個別ページ】
   │  A. 直リンク可の案件 → ASP紹介リンク・広告主LPに直接遷移
   │  B. 直リンク禁止傾向の案件(カテゴリ2・6等、将来追加時)
   │     → 自分の紹介記事・簡易LP(比較ページ等)を経由 → そこからASPリンク
   ▼
【広告主LP・申込ページ】
   │  ④無料体験/無料登録の心理的ハードルが下がっているか
   ▼
【成約(CV)】
```

### 各段階の役割整理

| 段階 | 目的 | 主担当 | ここで失敗すると起きること |
|---|---|---|---|
| 投稿 | 足を止めさせ、プロフィールへ興味を持たせる | ライティング担当 | そもそも見られない・スクロールされる |
| プロフィール | 「このアカウントは自分向けだ」と確信させる | 導線設計担当(本ファイル) | プロフィールは見たがリンクを押さない |
| リンク集 | 今の自分に合う商品をすぐ見つけさせる | 導線設計担当(本ファイル) | 案件が多すぎて/分かりにくくて離脱 |
| 個別ページ・LP | 申込・購入への最後の後押し | 商品選定担当が選んだ広告主LP依存 | LP自体が悪いと申込されない(自分では制御不可な部分だが、直リンク禁止案件は自作LPで補強可能) |
| 成約 | 収益発生 | ASP側の計測 | ここまで来て離脱するのが一番もったいない |

**重要**: 投稿は「入口」、プロフィール〜リンク集は「自分でコントロールできる区間」です。企画・ライティングがどれだけ優れていても、この区間の言葉が投稿と食い違っていたり、リンクが探しにくかったりすると、せっかく興味を持った人がここで脱落します。投稿の完成度と同じ熱量でこの区間を作り込んでください。

## プロフィール文案

戦略ファイルの方針(実体験型・共感ベース、権威型は避ける、煽り文句禁止、「属性+テーマ」のネーミング)に沿って3パターン作成します。いずれも「①誰の何を解決するか」「②実績・信頼性(誇張なし)」「③リンクへの誘導文言」の3要素を含みます。

### 共通ルール
- 実績は「フォロワー数」「収益額」等の誇張しやすい数字ではなく、**継続期間・試した数・属性の具体性**で信頼性を出す(例:「会社員6年目」「毎日投稿◯日目」「実際に使ったツール◯個」)。
- 「絶対」「誰でも」「必ず」等の断定・煽り表現は一切使わない(戦略・商品選定ファイル双方の申し送り事項)。
- リンクへの誘導文言は、投稿本文の最後のCTA・リンク集の1個目のラベルと必ず同じ言葉を使う(詳細は「CTA配置の一貫性」参照)。

### パターンA(オーソドックス・共感型)

```
アカウント名: ゆう|会社員6年目×AI活用で仕事を楽にする人

【プロフィール文】
毎日同じ作業に追われて、成長実感がなかった会社員6年目。
「AIを使えば楽になる」と分かってても何から試せばいいか分からず放置してました。
実際に使って良かったツール・学び直しの記録を発信中。
↓今日から試せるものだけ、厳選してまとめてます
```

### パターン(B) 悩み共感を前面に出すバージョン

```
アカウント名: りく|「何から始めればいいか分からない」を1つずつ解決

【プロフィール文】
スキルアップしたいのに、何から手をつければいいか分からず時間だけ過ぎていく…
そんな自分に効いたツール・サービスだけ実体験ベースで紹介してます(会社員/毎日投稿中)。
↓まずはコレだけ、と思えるものをリンクにまとめました
```

### パターンC(継続・仕組み化を軸にしたバージョン)

```
アカウント名: なお|三日坊主だった会社員が学び直しを続けられた記録

【プロフィール文】
資格勉強も学び直しも、いつも三日坊主でした。
「続かないのは意志が弱いからじゃなく仕組みの問題」と気づいてから変わった、実際に使ったツール・サービスを実体験で紹介中。
↓今の自分に合いそうなものから見てみてください
```

### 各パターンの使い分け
- パターンA: 汎用。最初はこれを基本形として運用開始することを推奨。
- パターンB: 「何から始めればいいか分からない」系のフック投稿を多く出す時期に寄せる場合。
- パターンC: 「続かない・三日坊主」系のフック投稿を多く出す時期に寄せる場合。

いずれも、`affiliate/02_research.md` の生の声（「成長実感がない」「何から手をつければいいか」「三日坊主」）をそのまま言葉として採用しており、想像で作った表現より刺さりやすい設計です。

## リンク集構成

lit.link / Linktree等のリンクまとめページを想定。**「まず何を見せるべきか」**を明確にするため、以下の優先順位・カテゴリ分けで構成します。

### 基本方針
1. 上から下に並べる際は「今すぐ役立つ度」「承認率の高さ(=成果につながりやすさ)」を優先する。単価の高さでは並べない。
2. カテゴリごとに見出しを分け、案件数が増えても迷わせない構成にする。
3. 期間限定・キャンペーン中の案件は専用の目立つ枠を作る。
4. 直リンク禁止傾向のカテゴリ(プログラミングスクール系・転職エージェント系)が将来追加された場合に備え、「経由ページ」を挟める拡張構成にしておく。

### 構成案(上から順)

```
[プロフィール画像・名前]
[一言紹介文]※プロフィール本文と同じトーンで1行

━━━ 期間限定 ━━━
📌 【今月限定】〇〇無料体験はこちら   ← キャンペーン中の案件があるときのみ表示。常設ではない

━━━ まずはコレ(一番おすすめ) ━━━
🎧 通勤中に学び直し|本要約サービスを試す      ← カテゴリ5(最優先着手・承認率高)
📚 何から始めるか迷ったらコレ|学習サービス一覧  ← カテゴリ1

━━━ 仕事を効率化したい人へ ━━━
🛠 実際に使ってるAI・業務効率化ツールまとめ    ← カテゴリ4(AI活用・重点テーマ)

━━━ 語学・自己投資を始めたい人へ ━━━
🗣 オンライン英会話、実際に試した感想はこちら   ← カテゴリ3

━━━ (将来追加エリア/現時点では非表示) ━━━
🎓 スクール選びで失敗しないための比較記事      ← カテゴリ2追加時。ASP直リンクではなく
                                                自分の比較記事(note/ブログ等)経由にする
💼 今の仕事を続けながら市場価値を上げる方法     ← カテゴリ6追加時。同上、経由ページ必須

[プロフィールに戻る/フォローはこちら]
```

### 設計のポイント
- **「まずはコレ」枠を固定で用意**: ペルソナは「何から始めればいいか分からない」層が多いため(`02_research.md`)、リンク集自体でも選択肢を絞り込んで最初に提示する。全部並列に並べると選べずに離脱する。
- **期間限定枠は常設リンクの上に一時的に出す**: 季節性(1月・3〜4月、GW前後、ボーナス時期)に合わせて商品選定・企画側とタイミングを合わせて出し入れする。
- **カテゴリ2・6を将来追加する場合の拡張ルール**（商品選定担当からの申し送り事項に対応）:
  - リンク集からASPの紹介リンクへ**直接**貼らない。「比較記事」「体験談記事」等の自分の経由ページ(note、簡易LP、ブログ記事等)へのリンクをリンク集に置き、その経由ページの中でASPリンクを使う2段階構成にする。
  - ラベルも「〇〇に無料登録」のような直接的な表現は避け、「比較記事を読む」「体験談を見る」など経由を前提にした文言にする。
  - この構成にしておけば、カテゴリ2・6が追加されても既存のリンク集レイアウトを崩さずに枠を差し込める。
- **ラベルの言葉は投稿・プロフィールの言葉と統一する**(次項で詳述)。

## 各段階の離脱対策

| 段階 | 主な離脱要因 | 対策 |
|---|---|---|
| 投稿 → プロフィール | ①CTAが弱く「続きはプロフィールへ」を入れ忘れる／②投稿本文だけで満足されて完結してしまう | 投稿本文の最後に必ず一貫したCTA文言を入れる(例:「実際に使ってるツールはプロフィールにまとめてます」)。企画・ライティング担当と合意した定型文を使い回す |
| プロフィール到達 → プロフィール離脱 | ①一目で「誰向けか」が分からない②実績が誇張っぽく見えて信頼されない③リンクへの案内が投稿の言葉と違い「あれ、話が違う」と感じる | 上記プロフィール文案の3要素(属性・実績・誘導)を必ず含める。誘導文言は投稿CTA・リンク集ラベルと統一。数字を使う実績は事実のみ記載し誇張しない |
| プロフィール → リンク集 | ①リンクをタップしても何のページか分からない不安②リンクが1個しかなくクリックしても得るものがなさそうに見える | プロフィールの誘導文言に「何が見られるか」を明記する(例:「実際に使って良かったものだけ厳選」)。単なる「リンクはこちら」ではなく中身が想像できる言葉にする |
| リンク集到達 → リンク集離脱 | ①案件が多すぎて選べない②ラベルが分かりにくい・抽象的③期間限定などの目立つ要素がなく全部同じに見えて後回しにされる | 「まずはコレ」枠で選択肢を絞る。カテゴリ見出しで分類。期間限定は視覚的に目立たせる(絵文字・枠を分ける等) |
| リンク集 → 個別ページ | ①クリックしたら期待と違うページに飛んだと感じる②直リンク禁止案件で経由ページを挟むと、ワンクッション増える分の離脱が起きやすい | ラベルの言葉と遷移先ページの中身を一致させる。経由ページを挟む場合は、経由ページ自体を簡潔にし(長い前置きをしない)、経由ページ内のCTAもリンク集のラベルと統一する |
| 個別ページ → 成約 | ①広告主LPの入力項目が多い・分かりにくい(こちらでは制御不可な部分)②「無料体験」等のメリットが伝わらないまま離脱 | 商品選定時点で承認率・LPの分かりやすさを考慮した案件を優先する(商品選定担当と連携)。自分の経由ページ側で「無料登録だけで試せる」等、心理的ハードルを下げる一言を添える |

## CTA配置の一貫性

投稿本文のCTA→プロフィール文言→リンク集のラベルの言葉を一致させることが、離脱を防ぐ最大のポイントです。以下のように「言葉の対応表」を運用ルールとして固定します。

### 対応表の例(パターンAプロフィールを使う場合)

| 段階 | 使う言葉 |
|---|---|
| 投稿本文の最後 | 「実際に使ってるツールはプロフィールにまとめてます」 |
| プロフィール誘導文 | 「↓今日から試せるものだけ、厳選してまとめてます」 |
| リンク集の見出し | 「まずはコレ(一番おすすめ)」 |

投稿で「無料体験できるツール」と書いたのに、プロフィールで「有料の学習サービス」の話をしていたり、リンク集のラベルが「〇〇公式サイト」のように無機質だったりすると、ユーザーは「話が違う」と感じて離脱します。企画担当・ライティング担当が新しい投稿の切り口を作るたびに、この対応表も一緒に更新し、常に3段階の言葉が揃っている状態を維持してください。

## 注意点

1. **直リンク禁止傾向のカテゴリ(プログラミングスクール系・転職エージェント系)は今回未着手だが、将来追加を見据えた構成にしてある**: リンク集の設計自体は商品選定担当（`affiliate-product-research`）からの申し送り事項に従い、2段階(リンク集→経由ページ→ASP)を前提とした拡張枠を用意済み。追加時はラベル文言・経由ページの中身を再度この担当と協議すること。
2. **プロフィール・リンク集の文言は必ずコンプライアンス確認の対象**: 「無料」「厳選」等の表現であっても、実態と異なれば景品表示法上の問題になりうる。プロフィール文案・リンク集ラベルは投稿原稿と同様に、公開前に必ず `affiliate-compliance` のチェックを通すこと。特に広告表記(#PR等)をどの段階(投稿/プロフィール/経由ページ)に入れるかは経路によって変わりうるため、コンプライアンス担当に必ず確認する。
3. **導線経由のクリック率・成約率は分析担当の結果を受けて定期的に見直す**: `affiliate-analyst` からプロフィールクリック率・リンククリック率・成約数の報告を受けたら、このファイルの「リンク集構成」「プロフィール文案」の優先順位・言葉を見直す。特にどのプロフィール文案(A/B/C)が最もリンククリック率が高いかはABテスト的に検証できるとよい。
4. **煽り文句・誇張表現は一切使わない**: 戦略ファイルの方針どおり、「絶対」「誰でも」「必ず稼げる」等は投稿だけでなくプロフィール・リンク集のラベルにも使わない。実績は誇張せず、継続期間や試した数など事実ベースの表現に統一する。
5. **投稿とリンク集の言葉がずれた瞬間に離脱が起きる**: この設計思想が本ファイルの最重要ポイント。新しい投稿ネタが増えるたびに「CTA配置の一貫性」の対応表を更新する運用を徹底すること。
